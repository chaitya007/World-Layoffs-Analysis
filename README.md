# 📊 World-Layoffs-Analysis

## Overview

This project analyzes a global layoffs dataset covering the period of the COVID-19 pandemic and the economic slowdown that followed. The dataset captures layoffs across companies, industries, countries, and years.

🔹 Key Operations:
   1. Data Cleaning: Removed duplicates, handled missing values, and standardized data formats.
   2. Exploratory Data Analysis (EDA): Analyzed trends in layoffs across industries, companies, country, stage and time periods.
